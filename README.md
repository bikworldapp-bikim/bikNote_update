# bikNote 업데이트

Windows와 Android 설치 파일을 배포하는 저장소입니다.

## 최신 버전 설치

- [Windows 설치 파일](https://github.com/bikworldapp-bikim/bikNote_update/releases/latest/download/bikNote-windows-setup.exe)
- [Android APK](https://github.com/bikworldapp-bikim/bikNote_update/releases/latest/download/bikNote-android.apk)
- [릴리스 목록](https://github.com/bikworldapp-bikim/bikNote_update/releases)

기존 앱에 자동 업데이트 기능이 없는 경우 이번 설치 파일을 한 번 직접 설치하세요.
Windows는 설치 후 생성된 bikNote 바로가기를 사용하세요.
Android는 기존 앱을 삭제하지 말고 APK를 설치하세요. 기기에서 설치 허용과 확인이 필요할 수 있습니다.

## 자동 업데이트

이번 버전부터 앱 시작 시와 6시간마다 새 버전을 확인합니다.
안내 창에서 업데이트를 선택하면 파일을 다운로드하고 SHA-256을 확인한 후 설치를 시작합니다.
업데이트 전에 작업을 저장해 주세요.

`update.json`은 앱에서 사용하는 버전, 다운로드 주소, 파일 크기와 SHA-256 정보입니다.
